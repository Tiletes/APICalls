Usage Notes

  • Reserved variables are computed at execution time and cannot be created, renamed, or deleted by users.
  • {{"{{"}}GUID{{"}}"}} generates a fresh UUID v4 per run — format: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.
  • {{"{{"}}GUID1{{"}}"}} generates a second, independent UUID v4 in the same format — use both in the same request to get two different values.
  • {{"{{"}}SERVICENAME{{"}}"}} reflects the Service Name field set on the selected template.
  • {{"{{"}}CURRENT_TIME{{"}}"}} uses the server's execution timestamp, e.g. 20260306-152012.
  • In the Execution module, tokens in blue are reserved variables whose values are filled in automatically before the request is sent.
  • You can still override a token value by editing the field manually before clicking Run.
